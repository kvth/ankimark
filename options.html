Base filter

Put in front of every rule, usually your deck. Any Anki search works, e.g. deck:"Japanese::Vocab" -is:suspended. Leave it empty to search your whole collection.

Rules

Each rule is an Anki search plus a colour. A word gets the colour of the first rule (top to bottom) that one of its notes matches. Notes matching no rule aren't highlighted. Card searches like is:due match a note if any of its cards match.

Fields

Which note fields hold the Japanese word. With none ticked, each note's first field is used.

Click “Load fields” to list the fields of your notes.

Display

Finds verbs and adjectives in any form (past, negative, polite, て-form, passive, causative, potential, …) and highlights the whole word. Off: only words written exactly as in your notes.

AnkiConnect

Default http://localhost:8765: Anki on this computer, or AnkiConnect Android on the phone. To use Anki on another computer, enter its address, e.g. http://192.168.0.20:8765, and set "webBindAddress": "0.0.0.0" in that AnkiConnect's config (better with an API key too, since anyone on the network can then reach your Anki).

A sync only reads notes that are new or edited since the last one, so frequent syncs stay cheap. Opening the popup also syncs when the last sync is over a minute old.

Backup

Save your rules and settings as a JSON file, or load them from one. Importing replaces the current settings. The Anki address and API key are not included.
